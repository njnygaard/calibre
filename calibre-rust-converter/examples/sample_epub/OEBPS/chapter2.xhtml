Chapter 2: Getting Started

Now that you understand what makes Rust special, let's get started with setting up your development environment and writing your first Rust program.

Installing Rust

The easiest way to install Rust is through rustup, the official Rust toolchain installer. Here's how to do it:

On Unix-like systems (Linux, macOS):

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

On Windows:

Download and run rustup-init.exe from https://rustup.rs

After installation, restart your terminal and verify the installation:

rustc --version
cargo --version

Your First Rust Program

Let's create a simple "Hello, World!" program to get started:

fn main() {
    println!("Hello, World!");
}

Save this code in a file named main.rs and run it with:

rustc main.rs
./main

Using Cargo

Cargo is Rust's package manager and build tool. It's much more convenient than using rustc directly. Here's how to create a new project:

cargo new hello_rust
cd hello_rust

This creates a new directory with the following structure:

hello_rust/
├── Cargo.toml
└── src/
    └── main.rs

The Cargo.toml file contains your project's metadata and dependencies:

[package]
name = "hello_rust"
version = "0.1.0"
edition = "2021"

[dependencies]

Building and Running

With Cargo, you can easily build and run your project:

  • cargo build - Compiles your project
  • cargo run - Compiles and runs your project
  • cargo check - Checks if your code compiles without producing an executable
  • cargo test - Runs your tests

Adding Dependencies

To add external dependencies, edit your Cargo.toml file:

[package]
name = "hello_rust"
version = "0.1.0"
edition = "2021"

[dependencies]
serde = "1.0"
tokio = { version = "1.0", features = ["full"] }

Then run cargo build to download and compile the dependencies.

IDE Support

Rust has excellent IDE support. Here are some popular options:

  • VS Code: Install the "rust-analyzer" extension
  • IntelliJ IDEA: Install the "Rust" plugin
  • Vim/Neovim: Use rust-analyzer with LSP
  • Emacs: Use rust-mode with rust-analyzer

Documentation

Rust has excellent documentation. You can access it locally:

rustup doc

This opens the Rust documentation in your browser, including:

  • The Rust Programming Language Book
  • Rust by Example
  • Standard library documentation
  • Cargo documentation
