Chapter 3: Basic Concepts

Now let's explore the fundamental concepts that make Rust work. Understanding these concepts is crucial for writing effective Rust code.

Variables and Mutability

In Rust, variables are immutable by default. This is a key feature that helps prevent bugs:

let x = 5; // immutable
// x = 6; // This would cause a compile error

let mut y = 5; // mutable
y = 6; // This works fine

The mut keyword explicitly declares that a variable can be changed. This makes the code's intent clear and helps catch accidental modifications.

Data Types

Rust is a statically typed language, which means the compiler must know the type of every variable at compile time. Here are the basic types:

Scalar Types

  • Integers: i8, i16, i32, i64, i128, isize
  • Unsigned integers: u8, u16, u32, u64, u128, usize
  • Floating-point: f32, f64
  • Boolean: bool
  • Character: char

Compound Types

// Tuples
let tup: (i32, f64, u8) = (500, 6.4, 1);

// Arrays
let a: [i32; 5] = [1, 2, 3, 4, 5];

Functions

Functions in Rust are declared with the fn keyword:

fn add(x: i32, y: i32) -> i32 {
    x + y // No semicolon means this is the return value
}

fn greet(name: &str) {
    println!("Hello, {}!", name);
}

Note that Rust uses snake_case for function names and the return type is specified after the arrow.

Control Flow

If Expressions

let number = 7;

if number < 5 {
    println!("condition was true");
} else {
    println!("condition was false");
}

Unlike many languages, the condition in an if expression must be a bool. Rust won't automatically convert non-Boolean types to Boolean.

Loops

Rust has three kinds of loops: loop, while, and for:

// Infinite loop
loop {
    println!("This will run forever");
    break; // Exit the loop
}

// While loop
let mut number = 3;
while number != 0 {
    println!("{}!", number);
    number -= 1;
}

// For loop
for element in a.iter() {
    println!("the value is: {}", element);
}

Ownership

Ownership is Rust's most unique feature and the key to memory safety. Here are the rules:

  • Each value has a variable that's called its "owner"
  • There can only be one owner at a time
  • When the owner goes out of scope, the value will be dropped
let s1 = String::from("hello");
let s2 = s1; // s1's value moves to s2, s1 is no longer valid

// This would cause an error:
// println!("{}", s1);

References and Borrowing

Instead of taking ownership, you can borrow a reference to a value:

fn main() {
    let s1 = String::from("hello");
    let len = calculate_length(&s1); // &s1 creates a reference
    println!("The length of '{}' is {}.", s1, len);
}

fn calculate_length(s: &String) -> usize { // s is a reference to a String
    s.len()
} // s goes out of scope, but it doesn't have ownership of what it refers to

Structs

Structs let you create custom data types:

struct User {
    username: String,
    email: String,
    sign_in_count: u64,
    active: bool,
}

let user1 = User {
    email: String::from("someone@example.com"),
    username: String::from("someusername123"),
    active: true,
    sign_in_count: 1,
};

Enums

Enums allow you to define a type by enumerating its possible variants:

enum IpAddrKind {
    V4,
    V6,
}

enum IpAddr {
    V4(String),
    V6(String),
}

let home = IpAddr::V4(String::from("127.0.0.1"));
let loopback = IpAddr::V6(String::from("::1"));

Pattern Matching

Rust's match expression is a powerful control flow construct:

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn value_in_cents(coin: Coin) -> u8 {
    match coin {
        Coin::Penny => 1,
        Coin::Nickel => 5,
        Coin::Dime => 10,
        Coin::Quarter => 25,
    }
}

These are the fundamental concepts that form the foundation of Rust programming. As you continue learning, you'll see how these concepts work together to provide memory safety and thread safety without garbage collection.

"Rust's ownership system is the foundation of its memory safety guarantees. Understanding ownership is essential for writing idiomatic Rust code."
